读这两张图的一句话:WorkHub 是「业务版 GitHub」——AI 当默认劳动力跑完一条 意图→执行→评审→置信→提议→人审→合并 的链路,任何改动都走提议、留快照、不直写生产;记忆/技能/预算在两端回灌。

当前局限(诚实标注):① 单 agent 执行,无层级子 agent / 无 meta-planner 拆解 ② 记忆只覆盖不归并 ③ 无 OKR ④ escalated 升级是死状态、未上决策队列。这四点正是 R9「agent 军团」要补的(见 r9-agent-army/)。
