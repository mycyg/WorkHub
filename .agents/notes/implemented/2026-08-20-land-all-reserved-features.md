# 全部预留功能落地，不允许「界面未上线」状态

- Status: implemented
- Date: 2026-08-20
- Owner: kimi-code（用户直接指令）

## Problem

接线审计+声明盘点发现 10 处「端点/声明在前，界面/实现欠账」的功能（OKR 列表、权限策略编辑、设备管理撤销、升级转交、撞车 choose、一键回滚桌面挂载、聊天 #/ 唤起、时间线 E3 起草、搜索直达会议、OpenAPI 标注缺失）。此前的处置口径是「保留预留口+标注未上线」，用户明确否决：**写的功能就要能用，不得存在「界面未上线」**。

## Decision

全部落地。盘点表即施工单（10 项，含每项缺口清单与工作量），逐批实现并真实测试。撤销「OpenAPI 标注界面未上线」的处置（功能上线后该标注失去意义）。

## Alternatives considered

- 保留预留口 + 标注（原口径）：用户否决。产品诚信优先级高于排期便利——README 承诺的「一键回滚」不能是打不开的按钮。
- 删除未接线的端点：对已写清服务层的功能属倒退，否决。

## Consequences

新增功能的完成标准：端点+服务+至少一端 UI+实测截图/测试。今后任何「先上端点后上 UI」的 PR 必须同批带 UI，否则不合并。
