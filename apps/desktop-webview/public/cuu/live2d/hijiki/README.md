# Cuu Hijiki Live2D Runtime Asset

This folder contains the current Cuu desktop-pet Live2D default candidate, based on the original black cat `hijiki` Cubism 2 model from `imuncle/live2d`.

Source reference:

- https://github.com/imuncle/live2d/tree/master/model/hijiki
