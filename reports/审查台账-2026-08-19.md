## 十、deepseek-harness 研读纪要与迭代方向（子代理 H）✅

仓库已 clone 至 `reference/deepseek-harness`。它是 DeepSeek 开源的 agent harness（`dsh`）：**"一切皆插件"**——agent 循环、会话日志、工具、系统提示、LLM 适配器全部是平等插件（底层 vendored Cordis 框架）。核心机制：

- **会话事件日志单一事实源**：硬不变量 "Model-visible ⟺ logged"，凡进模型请求的内容必须可从 append-only SessionEvent 日志重建 → fork/回放/遥测/审计全部免费从同一事件流派生。
- **可逆 effect 注册**：所有插件贡献走 `ctx.effect()` 返回 disposer，卸载即自动回滚 → 热重载天然成立。
- **能力缝三角色**：Service Definition / Provider / Consumer 必须成套（如 `ctx.fs` 有 local/sandbox/e2e 三个 Provider），缝清单由脚本生成、CI 校验新鲜度。
- **组合=分层补丁**：profile + bundle 按序叠加成运行时插件树，`--dump-config` 可审。
- **自我迭代三层**：① 运行时自省自改（`cordis_inspect/define/run/undefine` 五个工具，动态包只活内存、沉淀须走正式插件流程——实验与固化分界明确）；② Skills 分层目录（项目>用户>内置 rank 表，目录进 prompt、正文按需加载）；③ Agent Note 决策档案制度（proposed/implemented/rejected/archived 生命周期，格式有脚本门禁）。
- **质量护栏**：四层测试含「keyless 快照回放」（录制真实会话、无密钥回放 diff 整机输出）+ 逐文件 100% 覆盖率门禁。
