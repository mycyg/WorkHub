# Markdown 报告约定

无需额外库。这是写作合同，不是代码模板。

## 结构（按序）

```markdown
# <一句话点题的标题>

## 结论
<3 条以内，每条一句话，可独立被引用>

## 依据
<每条结论对应的数据/事实，注明来源（文件名/段落/数字出处）>

## 详细内容
<正文，按主题分二级标题；表格用 markdown table>

## 待确认与下一步
<还需要谁确认什么、缺哪份材料、建议的下一步>
```

## 约定

1. 产物存 `outputs/`，文件名小写连字符。
2. 结论先行——审批者 30 秒内能判断采纳与否。
3. 引用任务给的材料时注明出处；**没有依据的数字不要编**，写"待确认"并列入未尽事项。
4. 表格不超过 8 列；长清单用列表不用表格。
5. 中英文之间留空格；单位与数字不分行。
