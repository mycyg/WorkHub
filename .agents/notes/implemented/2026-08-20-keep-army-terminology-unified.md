# 保留「军团」作为产品词，但两端统一

- Status: implemented
- Date: 2026-08-20
- Owner: kimi-code（审查遗留决策项 WEB-05/术语一致性）

## Problem

「军团」（agent army）是内部 codename（r9-agent-army）的外露。审查发现 web 端用「军团」、桌面端用「Cuu 的小队」，且页面标题残留「智能代理军团」——同一概念三种叫法。是否需要换掉「军团」这个词本身存在争议（军事化色彩 vs 产品个性）。

## Decision

保留「军团」作为正式产品词（它有辨识度，且 r9 愿景文档就是以它为骨架写的），但**两端必须只用一个词**：全站统一「军团」，删除「小队」「智能代理军团」残留。它不是黑话（用户能理解「一队 AI」），问题在于不统一，不在于词本身。

## Alternatives considered

- 改成「AI 团队/小队」：更温和但失去辨识度，且改动面大。否决。
- 双端各保留各的：否决，术语纪律的核心就是一处一词。

## Consequences

桌面端「Cuu 的小队」全部改「军团」；文案门禁的术语表把「军团」列为正式词。若未来做企业客户评审觉得不妥，再开 Note 复评。
