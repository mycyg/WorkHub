# 团队周会纪要模板（最终版）

> 版本：v1.0（复核修订）｜适用：团队每周例会｜来源工单：DAY0PILOTPRO-013

## 填写说明（每次开会前必读，共 5 条）

1. **章节固定**：本模板固定为「阻塞 / 进展 / 下周计划」三节，不得删节；某节本周无内容时写「无」，不要留空。
2. **占位符用法**：所有【】内文字均为提示语，填写时用实际内容替换并删除【】本身，例如【事项名称】→ 支付网关联调；需要新增行时，复制表格中任意一行修改即可。
3. **每次新建一份**：复制本模板另存为 `YYYY-MM-DD-周会纪要.md`（如 `2024-06-28-周会纪要.md`），上一期文件归档，不覆盖不串改。
4. **进展须对上期目标**：「进展」一栏逐项对照上期「下周计划」勾对；未完成事项明确写入「阻塞」或顺延至「下周计划」，并注明原因。
5. **会后跟进**：会后 24 小时内由记录人分发纪要，各行动项负责人需确认收到；状态列只能使用模板给定的取值，不要自造词。
