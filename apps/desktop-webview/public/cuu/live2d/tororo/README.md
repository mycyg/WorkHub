# Cuu Tororo Live2D

This folder contains the original Tororo white cat Live2D Cubism 2 sample model used by WorkHub during the concept implementation phase.

- Source reference: `https://github.com/imuncle/live2d/tree/master/model/tororo`
- Runtime entry: `cuu-tororo.html`
- Model manifest: `cuu-tororo.model.json`

Tororo is one of the two allowed Cuu desktop-pet appearances together with the Hijiki black cat. Commercial release still needs explicit rights clearance or an original equivalent model.
