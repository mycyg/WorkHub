# R16 工作台重设计(NewMax 参考)

## 用户拍板(2026-07-16,原型 v1 反馈)

1. **信息架构以项目分组为主轴**(v1 跑偏成全局扁平对话列表):左 nav = 项目分组,每个项目下挂 **群聊(主区)/ 单聊&协同会话 / 成员管理**;全局私聊(跨项目 DM)保留独立分组;「最近对话」降级为次要或并入项目分组,不做主轴。项目 tab 视图加「成员」一席(五 tab → 对话/成员/日程/任务/文件/设置,或成员独立 tab)。
2. **视觉 = 我们的液态玻璃,透明度调低**(不用参考的纸感):ds-glass 体系,实底感更强(约 .85-.92 白底 + 毛玻璃),保持桌面 vibrancy 兼容。NewMax 只抄信息架构与组件形态,不抄视觉。
3. **在现有工作台交互基础上迭代,不推倒**(第二次补充拍板):基座=现状三栏(rail 项目树[主区/协同/成员]+私聊分组+待拍板入口 / 中栏 tab 体系 / 右栏面板)。NewMax 元素全部作为**增量**:聊天流升级(模型归因/思考折叠/工具摘要/操作条)、中栏会话 tabs(温和增强)、+任务看板 tab、+日程 tab、+设置 tab(自定义指令)、右栏加「工作区文件」模式(变动/所有)、编辑器+AI 改写视图、成员管理动作。**不引入顶部项目 tabs**(保持 rail 选项目),不做全局最近对话。施工分批 W1-W5 相应重排:不再有"外壳重 IA"大批,改为逐 tab/逐面板增量批。

## 参考的信息架构(NewMax)

1. **顶部工作区 tabs**:浏览器式,多工作区并开,+ 新建。
2. **最左窄 nav**:新建对话/搜索/定时任务/浏览器/Skill 管理/每日回顾;下方「长期计划」(项目列表)、「最近对话」(按日分组)、归档、用户。
3. **中央会话区**:会话 tabs(一工作区多会话并开)→ 聊天流:模型归因行(Grok 订阅/grok-4.3)、「深度思考 N 秒」折叠、「执行终端命令 ×5,读取文件 ×8」工具摘要折叠、markdown 富渲染、文件产出卡(+查看此任务所有文件)、消息操作(复制/重试/分享 + 耗时·tokens + N/N 分页)。
4. **右侧工作区文件面板**:「变动文件 / 所有文件」两 tab 的文件树,搜索/隐藏/新建。
5. **文档编辑器**(右分栏,文件 tab 化):富文本工具栏、编辑/源码/预览/移动/双栏视图切换、导出/已保存;**AI 改写侧板**:选中文字→润色/扩写建议卡(模型归因+拒绝/接受),正文 tracked changes(红删绿增)。
6. **项目(长期计划)视图五 tab**:对话(项目会话列表)/日程(左=计划文档渲染,右=周历+任务卡,创建任务/今天)/任务(四列看板 Todo/进行中/已完成/Review,卡片=标题+日期+手动标签,可拖)/文件/设置(基础/任务默认/长期记忆/工作 Skill/通知;含「自定义指令」项目级 prompt,失焦自动保存)。
7. **Composer**:+/Skill/核对/目标 图标、「联网」toggle、模型选择器、语音;占位「输入消息…(输入 / 召唤 Skill)」。
